# QPet Website Development Project 

 
## 1.	BRIEF DESCRIPTION
### 1.1 WHO IS QPET?
QPET is a South African packaging manufacturer producing PET preforms, jars, closures, and bottles supplying industries such as edible oils, food, water, chemicals, and carbonated beverages. Operating out of Pietermaritzburg, Johannesburg, and Cape Town. 

We are collaborating with QPet to develop and design a modern, public-facing website. This project aims to enhance QPet’s online visibility while presenting its company information and product catalogue in a structured, professional manner. 

During the initial consultation, QPet identified an opportunity to improve how it presents information to the public, with the use of a user-friendly online catalogue. This organised platform serves both prospective and existing clients with a seamless, fast access to the company's complete range of products and its essential information.

The proposed project will deliver a professional database supported website for QPet’s corporate profile and product catalogue. Site visitors will be able to explore the background of the company, locate branch contacts, filter through product listings with approved details and images and submit enquiries online. 

By housing product information in a structured database, the platform supports future catalogue expansion and simplifies content updates. 

Enquiries logged via the website will be securely stored in the database and immediately routed to the designated QPet sales-contact through email, establishing a consistent and clear communication workflow. To remain aligned with its core objective, the system will not incorporate online shopping carts, customer accounts, order management features, or payment processing, as its current aim is to deliver product and company information rather than operate as a full e-commerce platform.


The web solution is in alignment with QPet’s goals by establishing a dedicated, professional hub to highlight its company accomplishments, product range, branch network, and operational facilities. 
It allows clients to effortlessly explore available products prior to reaching out, offering an accessible pathway for submitting enquiries when commercially sensitive details or technical specifications cannot be publicly displayed. Designed on a structured database, the platform guarantees a maintainable foundation that can seamlessly scale and evolve as QPet’s future digital needs expand.

### 5.1	 REQUIREMENTS/ PRE-REQUISITES 
Before running the application, ensure that the following is installed on the local development machine:
-	Visual Studio 2026 
-	.NET 10 SDK 
-	A modern web browser (e.g. Google Chrome, Microsoft Edge, Firefox or Safari)
---------------------
### 5.2	CLONE THE REPOSITORY 
The project can be cloned directly from GitHub without using the command line 

USING GITHUB + VISUAL STUDIO 
1.	Open the QPet project repository on GitHub.
2.	 Click the green Code button.
3.	Select HTTPS.
4.	 Copy the repository URL.
5.	Open Visual Studio and Paste the repository URL into the Repository location field.
6.	Select the folder where you would like to save the project.
7.	Click Clone.
8.	Visual Studio will download the project and open it automatically.
---------------------
### 5.3	RESTORE PROJECT DEPENDENCIES 
After cloning the repository, Visual Studio should automatically restore the required NuGet packages.
If the packages are not restored automatically:
1.	Open the project in Visual Studio.
2.	In Solution Explorer, right-click the solution.
3.	Select Restore NuGet Packages.
4.	Wait for the package restoration to complete.
5.	Ensure there are no package or dependency errors in the Error List.

### 5.7	 RUN THE APPLICATION 
To run the application using Visual Studio:
1.	Open the QPet solution in Visual Studio.
2.	Ensure the correct project is selected as the Startup Project.
3.	Select the HTTPS launch profile.

---------------------
### 5.8	 RUN AUTOMATED TESTS 
Automated tests can be run directly through Visual Studio.
1.	Open the QPet solution in Visual Studio.
2.	Select Test from the top menu.
3.	Select Test Explorer.
4.	Wait for Visual Studio to discover the available tests.
5.	Click Run All Tests.
6.	The results will be displayed in the Test Explorer window.
